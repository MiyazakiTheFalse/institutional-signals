# Delivery backlog and acceptance gates

## P0 — Foundation (starter package contains this)

- [x] Written architecture, risks, protocol and source catalogue.
- [x] Versioned observation and forecast registers with provenance.
- [x] Static website implementation and Python export.
- [x] Basic validation tests and CI workflow.
- [ ] Create remote GitHub repository and push.
- [ ] Confirm CI green on GitHub.
- [ ] Connect Cloudflare Pages and verify public/private staging choices.

**Gate:** Every source entry displayed has a working original URL, dates, authority and verifiable categorisation; site builds without secret keys.

## P1 — First serious study

- [ ] Choose precise binary decision and resolution criteria.
- [ ] Baseline probability justified and locked before closing time.
- [ ] Add competing explanations and researcher audit notes.
- [ ] Resolve prediction from an independent document and score it.

**Gate:** A third party can reproduce the forecast question, evidence cutoff and outcome without trusting the author.

## P2 — Collection and analysis

- [ ] Integrate Parliament API with schema checks and retries.
- [ ] Ingest original Ofwat spreadsheet and data dictionary; verify licenses and normalise definitions.
- [ ] Optional Companies House API ingestion (secret key and rate limit handling).
- [ ] Archive snapshots and change detection.
- [ ] Pilot baseline modelling on enough historical institution-decisions; publication bias and leakage audit.

**Gate:** CI and data QA pass; each transformed value traces to original source/version.

## P3 — Public research product

- [ ] Accessibility, keyboard and mobile audit.
- [ ] Email digest for new independently verified evidence (consent-based).
- [ ] Transparent change log and correction process.
- [ ] Test demand for research briefings without representing hypotheses as investment recommendations.

**Gate:** User feedback, zero paid services, and evidence users find the work useful.
