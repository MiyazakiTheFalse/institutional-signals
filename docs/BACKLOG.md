## Cost policy

No paid GitHub testing, larger runners, unapproved commercial APIs or surprise infrastructure commitments. Use standard GitHub public-repository runners, reviewed dependency changes, on-demand installer packaging and short artifact retention. Account billing budgets/alerts and any Cloudflare usage limits must be checked by the owner separately; repository files cannot guarantee zero charges.
