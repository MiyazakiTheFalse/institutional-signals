# Institutional Signals

An evidence-backed research project tracking institutional decisions and testing dated, falsifiable predictions. Initial case: Thames Water and Ofwat.

## Status

Repository scaffold only. No live ingestion, dashboard deployment, or validated predictions yet.

## Planned stack

Python ingestion; DuckDB/Pandas analysis; JSON/Parquet storage; GitHub Actions scheduling; React, TypeScript, Tailwind and Apache ECharts dashboard on Cloudflare Pages. Target: no paid APIs, database, or domain for the research MVP.

See [design](docs/design.md) for the implementation plan.
